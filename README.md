# Simulation-
**DOS Elite Bank** is a browser-based banking simulation project designed to demonstrate a simple and interactive banking system. It allows users to create an account using their legal name, monthly salary, and a secure PIN, followed by an OTP verification process. Once logged in, users can view their available balance, make deposits and withdrawals, and monitor their transaction history. The system also provides basic AI-powered financial guidance based on the user's current balance. Account information and transaction data are stored locally in the browser using localStorage, making this project suitable for demonstration and educational purposes rather than real-world banking or financial transactions.
